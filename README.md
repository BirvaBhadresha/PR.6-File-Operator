## Description

Personal Journal Manager is a Python-based console application that allows users to create, view, search, and delete journal entries. Each entry is automatically saved in a text file along with the date and time.

## Features

* Add new journal entries
* View all saved entries
* Search entries using a keyword or date
* Delete all journal entries
* Automatically records date and time for each entry
* Stores entries permanently in `journal.txt`

## Technologies Used

* Python
* `datetime` module
* File Handling
* Object-Oriented Programming (Class and Methods)
* Exception Handling

## How to Run

1. Make sure Python is installed on your computer.
2. Save the program as:
   `journal_manager.py`
3. Open a terminal or command prompt in the program folder.
4. Run:
   `python journal_manager.py`

## File Created

The program automatically creates a file named:

`journal.txt`

This file is used to store all journal entries.

## Menu Options

1. **Add a new Entry** – Adds a new journal entry with a timestamp.
2. **View All Entries** – Displays all saved entries.
3. **Search for an Entry** – Searches entries using a keyword or date.
4. **Delete All Entries** – Deletes all saved journal entries.
5. **Exit** – Closes the program.

## Conclusion

This project demonstrates the use of **Python classes, file handling, date and time, loops, user input, and exception handling** to create a simple personal journal management system.
